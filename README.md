# SENER_Analisis_Requisitos

Tablero de Análisis de Requisitos de Certificados de Energías Limpias (CEL) 2025-2039.

Este proyecto contiene visualizaciones interactivas (HTML + Highcharts) de:
1.  Metodología de Cálculo de Requisitos.
2.  Pronóstico de Generación de Energía Limpia.
3.  Indicador de Participación de Energías Limpias vs Requisito.
4.  Porcentaje de Requisito Anual Oficial.
5.  Calculadora de Obligación por Participante.

## Estructura
*   `index.html`: Menú principal de navegación.
*   `*.html`: Gráficos individuales.
*   `img/`, `css/`, `js/`: Recursos estáticos.
*   `Análisis Requisitos de CEL.pdf`: Documento base del análisis.
